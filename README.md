

## 📌 Descripción

En esta rama se realizó una reorganización estructural del proyecto con el objetivo de mejorar la mantenibilidad, escalabilidad y claridad del código.

Este sprint se enfocó en la **refactorización del CSS** y en la creación de una arquitectura modular basada en componentes.



---

## 🏗️ Cambios Implementados

### 📁 Nueva Estructura de Carpetas

Se creó la carpeta principal:
/blocks

Dentro de ella se modularizaron los siguientes componentes:

blocks/
│
├── blog/
├── boton/
├── contac/
├── footer/
├── hero/
├── navbar/
├── projects/
└── sobre-mi/

Cada carpeta contiene sus respectivos estilos y/o archivos asociados al componente.

---

### 📦 Carpeta Vendor

Se creó una carpeta adicional:


/vendor

Contiene:

- `normalize.css`
